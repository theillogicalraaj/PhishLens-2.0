# Security Boundary

PhishLens is a defensive security-awareness simulation platform. It is designed to measure employee behavior using authorized, synthetic simulations.

## Safety guarantees

- No password or credential collection.
- No credential replay or authentication bypass.
- No real phishing delivery is included in the default application.
- Simulation events are recorded as application events.
- IP addresses are hashed before storage in event records.
- Training pages should be hosted only on infrastructure controlled by the organization.

## Responsible deployment

Before any real-world awareness campaign, obtain written authorization, define scope, provide escalation contacts, exclude sensitive populations as required by organizational policy, and use an approved internal mail/domain infrastructure.

The project should be treated as an awareness-testing platform, not as a toolkit for impersonation or credential theft.
